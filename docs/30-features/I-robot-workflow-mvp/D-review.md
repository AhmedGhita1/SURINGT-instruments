# review and acceptance

> records the specialist review of the completed robot workflow implementation and its verification evidence, and the user's final decision.

**status:** pending implementation

## A. review

review exactly-once behavior, real-time integration, item-resolution timing, ordering, state transitions, degradation, safe failure, tray isolation, operator presentation, provenance, and performance evidence. End with `pass`, `pass-with-follow-ups`, or `fail`.

## B. acceptance

record the final decision, unresolved follow-ups, and any product or architecture feedback that must persist elsewhere.
